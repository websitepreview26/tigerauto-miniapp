# TigerAuto · HTML-демо

Откройте `index.html` или запустите `python3 -m http.server 8765` и перейдите на http://localhost:8765.

Для Cloudflare Pages загрузите папку с `index.html` через Direct Upload. Команда сборки и зависимости не нужны.

Сценарий презентации: «Заменить стекло» → «Заполнить примером» → «Далее» → создать обращение → «Менеджер» → «Пример» → отправить предложение → «Клиент» → выбрать вариант и подтвердить → «Менеджер».

Ремонт: выберите «Устранить скол или трещину», добавьте фото, заполните пример предложения менеджера и вручную укажите стоимость. Для консультации менеджер отправляет текстовый ответ.

Все заявки, фотографии, черновики и переписка сохраняются только в localStorage этого браузера. Фотографии уменьшаются перед сохранением. «Сбросить демо» удаляет эти данные. Демо не синхронизируется между устройствами и не отправляет данные.

Примерные цены 150 / 195 / 286 BYN доступны только для замены лобового стекла Volkswagen Passat B6 2005–2010 и взяты из предоставленного PDF. Остальные цены вводятся вручную. Это демонстрационные данные, не актуальный прайс.
